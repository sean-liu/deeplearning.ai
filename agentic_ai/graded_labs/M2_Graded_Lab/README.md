# Agentic AI Module 2 · Reflection in a Research Agent

This graded lab practices the reflection pattern by drafting, critiquing, and revising an essay with language models. The notebook contains the original exercise template.

## Local setup

From the repository root, install the lab dependencies and prepare its Jupyter kernel.

```bash
python3 tools/prepare.py agentic_ai/graded_labs/M2_Graded_Lab
```

Open [C1M2_Assignment.ipynb](C1M2_Assignment.ipynb) with the repository’s Python 3.12 kernel. The model calls require your own `OPENAI_API_KEY` in the local environment. To use the course’s submission interface, open the lab on the [DeepLearning.AI course platform](https://www.deeplearning.ai/courses/agentic-ai/).

The course files in this directory are for private study. See [DeepLearning.AI’s Terms of Use](https://www.deeplearning.ai/terms-of-use/).
