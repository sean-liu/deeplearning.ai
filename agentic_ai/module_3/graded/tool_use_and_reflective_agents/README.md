# Agentic AI Module 3 · Tool Use and Reflective Agents

This graded lab builds a research agent that searches arXiv and Tavily, reviews its draft, and turns the revised report into HTML. The search tools are defined in `research_tools.py`.

From the repository root, prepare the lab and select the repository’s Python 3.12 Jupyter kernel.

```bash
python3 tools/prepare.py agentic_ai/module_3/graded/tool_use_and_reflective_agents
```

Open [GL-M3.ipynb](GL-M3.ipynb). Live runs require your own `OPENAI_API_KEY` and `TAVILY_API_KEY` in the local environment.
